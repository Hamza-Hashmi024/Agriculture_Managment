# Arthi Businnes System

A modern web application built with **React, TypeScript, Vite, TailwindCSS, and shadcn/ui**.  

---

##  Features  
-  Fast development with Vite  
-  Styled with Tailwind CSS + shadcn/ui components  
-  Modular React + TypeScript structure  
-  Fully responsive and mobile-friendly  
-  Easy to extend and customize  

---

## 🛠️ Tech Stack  
- **Frontend**: React, TypeScript  
- **Styling**: Tailwind CSS, shadcn/ui  
- **Build Tool**: Vite  

---

##  Installation & Setup  

### Prerequisites  
- Node.js >= 18  
- npm or yarn

```sh




# Install dependencies
